eBay API Status

Live sold listings are pulled through a backend proxy usingfindCompletedItemsand stored in localStorage for persistent trend tracking without exposing credentials in browser code.

  1. Proxy endpoint: /api/ebay/completed-items
  2. Default local proxy URL: http://localhost:8787
  3. Backend env vars required: EBAY_APP_ID, EBAY_DEV_ID, EBAY_CERT_ID
  4. Historical snapshots are persisted in localStorage key sports-card-tracker-history-v1
